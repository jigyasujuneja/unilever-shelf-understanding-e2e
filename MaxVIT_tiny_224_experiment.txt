Simple Model-Training Flow
Read rpc.json from GCS
        ↓
Read classes, gallery and dataset splits
        ↓
Create SKU ID ↔ model-index mapping
        ↓
Combine gallery and training records
        ↓
Deduplicate records using image URI
        ↓
Create training and validation datasets
        ↓
Download images from GCS when requested
        ↓
Cache downloaded images locally
        ↓
Apply training or validation transformations
        ↓
Load images in batches using DataLoader
        ↓
Initialize pretrained MaxViT-Tiny
        ↓
Replace output layer with 1,922 classes
        ↓
Run forward pass
        ↓
Calculate cross-entropy loss
        ↓
Backpropagate gradients
        ↓
Update model using AdamW
        ↓
Validate after every epoch
        ↓
Update cosine learning-rate scheduler
        ↓
Save model when validation accuracy improves
        ↓
Export PyTorch and TorchScript models
        ↓
Moved the model and Model-index-to-class metadata mapping  manually to GCP for inference
