Node 4: System-1 DiffusionGemma (`/v1/systemone` 64-Token Pinned Canvas • `mmastrac/djev`)
1. What It Means (ML & Tensor Mechanics):

Instead of autoregressive left-to-right token generation (O(N) serial forward passes), `/v1/systemone` takes a fixed 64-token canvas where 89.1% (57 tokens: JSON keys + high-confidence Brand/Category) are pinned (`diffusion_pinned=true`), and denoises the 7 masked `[MASK]` slots (`Packaging`, `Size`, `Base Pack Code`) in 1 parallel bidirectional forward pass (42 ms).

2. Why We Chose It (What Failed Before):

Standard autoregressive VLMs (`Gemini Flash-Lite` / `LLaVA`) take 600–2,600 ms per crop and waste 85% of compute re-emitting static JSON boilerplate keys (`"category":`, `"brand":`). System-1 discrete diffusion cuts tail latency by 14× while attending bidirectionally to both left and right shelf neighbors.

3. Measured Ablation Delta & Trade-Off:

+5.4% accuracy gain over Pure Vector Retrieval (`96.8%` vs `91.4%`) on sister-variant sizes (`Dove 650ml` vs `750ml`), while reducing per-image cost 4.7× (`₹0.020` vs `₹0.094` on 2-Stage Autoregressive Crop VLM).
